# Create: Atomic  (Minecraft 1.21.1 · NeoForge · Create 6.0.x)

Аддон к Create: руда радиции, топливные стержни, водяное охлаждение и ядерный реактор,
который вращает вашу кинетическую сеть.

## Сборка

Нужны Java 21 и интернет (для скачивания зависимостей).

    gradle wrapper --gradle-version 8.12.1     # один раз, если нет gradlew
    ./gradlew build                            # jar в build/libs
    ./gradlew runClient                        # запуск клиента с Create

Или откройте папку в IntelliJ IDEA как Gradle-проект.

## Геймплей

1. Найдите **руду радиции** (Overworld, Y -64…16). Рядом с рудой и самими предметами растёт эффект
   **Радиация** (голод; у отработанного топлива и при аварии ещё и урон).
2. Дробите руду на дробильных колёсах Create -> **дроблёная радиция** -> печь/плавильный вентилятор -> **слиток**.
3. Крафт: **топливный стержень** (2 слитка + 4 железных листа), **корпус реактора**, **активная зона**
   (корпус, вал, слитки, механизм точности).
4. Поставьте активную зону, подключите **валы с двух концов оси**, окружите остальные 4 стороны
   **источниками воды** (проточная вода не считается).
5. ПКМ стержнем - загрузить (до 4). ПКМ пустой рукой - запуск / аварийная остановка (SCRAM).
   Shift+ПКМ пустой рукой - выгрузить стержни и отходы.
6. Нагрев: каждый стержень +2 за 0.5 с, каждый источник воды -2. **Источников воды должно быть не меньше,
   чем стержней.** При 100% нагрева - взрыв и смертельное излучение в радиусе 32 блоков.
7. Мощность: 64 об/мин, 256 су/об на каждый стержень (4 стержня ~ 65 536 су). Топлива хватает на 5 минут.
